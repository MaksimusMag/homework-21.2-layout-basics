# Домашняя работа №11: 21.2 Основы верстки

## Описание
Простое веб-приложение на Python (без фреймворков) для демонстрации основ HTTP-сервера и верстки с Bootstrap. Реализована страница «Контакты», обработка ошибок (404, 500) и прием POST-запросов.

## Структура проекта
- html/ — HTML-шаблоны страниц (Контакты, 404, 500).
- server/app.py — HTTP-сервер на стандартной библиотеке http.server.
- .flake8 — конфигурация линтера flake8.

## Требования
- Python 3.13+
- Виртуальное окружение (рекомендуется)

## Установка и запуск
1. Создайте виртуальное окружение (если еще не создано):
   python -m venv venv
   .\venv\Scripts\activate

2. Запустите сервер:
   python server/app.py

3. Откройте в браузере: http://localhost:8000/contacts

## Функционал
- GET /contacts: Возвращает страницу контактов (Content-Type: text/html). Чтение файла через контекстный менеджер.
- POST /contacts: Принимает данные формы и выводит их в консоль (дополнительное задание).
- Обработка ошибок: При запросе несуществующей страницы отдается 404.html, при внутреннем сбое — 500.html.
